# Supervisor review checklist

Used by the supervisor when reviewing a proposal draft. Students: pass this before you submit, and you will receive comments on substance rather than on omissions.

Scoring: for each item, **Pass / Revise / Missing**. A proposal goes to the committee only when every item is Pass.

| # | Criterion | Pass / Revise / Missing | Comment |
|---|---|---|---|
| 1 | Problem statement is precise, quotable and stands alone | | |
| 2 | Gap is established by the literature, not asserted | | |
| 3 | Research question is bounded, falsifiable and answerable with the proposed method | | |
| 4 | One aim; three to five measurable objectives traceable to the question | | |
| 5 | Scope and delimitations stated | | |
| 6 | Literature is argued thematically; closest prior work identified and differentiated | | |
| 7 | Comparison table of prior studies present | | |
| 8 | Method choices justified against alternatives | | |
| 9 | V&V plan: code verification, solution verification, named validation dataset, UQ | | |
| 10 | Test matrix with cost estimate | | |
| 11 | Preliminary results present (or an explanation of why not) | | |
| 12 | Timeline realistic: writing early, deliverable milestones, contingency | | |
| 13 | Resources secured or with a credible path | | |
| 14 | Risk register with controllable mitigations | | |
| 15 | Ethics route confirmed; data management plan present | | |
| 16 | AI use disclosed and consistent with the Lab's Guardrails; prose passes the viva test | | |
| 17 | Writing: UK English, units, nomenclature, figures, captions, template compliance | | |
| 18 | References: all read; style correct; no unverifiable citations | | |
